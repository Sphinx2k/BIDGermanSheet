# Blades in the Dark – Deutscher Papierbogen

Alternatives Charakterblatt für Foundry VTT 14 und **Blades in the Dark 6.1.2**.

## Was ist der Deutsche Papierbogen
Ich war nicht zufrieden mit den vorhandenen Charakter und Gang Bögen. Die PDF Version hat alles nötige auf einer DinA4 Seite und in Foundry ist es über X Tabs verteilt gewesen. Ich habe versuche so viel wie möglich auf einer Seite ohne Scrollbalken unterzubringen. Das Original nutzt recht kleine Schrift weshalb meine Version in FoundryVTT etwas größer ausfällt.

Der Charakterbogen lässt sich auch Sperren sodas man nicht versehentlich irgendwo einen Punkt wegklicken kann. Gegenstände, Schaden und Stress kann man aber auch bei gesperrtem Bogen noch ändern da das während einem Coup öfter nötig ist. 

Ich habe beim Charakterbogen das Feld für entfernt. Da die meisten Spieler ihre Notizen im Journal oder außerhalb von FoundryVTT ablegen. Es gibt aber oben einen Knopf links neben dem Sperrfeld wo man sich Notizen machen kann.

Das Modul übersetzt auch alle englischen Begriffe in die entsprechende Deutsche Version. Was evtl. das Übersetzungsmodul überflüssig macht (werde ich selbst noch testen)
